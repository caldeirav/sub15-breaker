      What each component is responsible for
        
      
          
      agentgateway — transport
      Managed connectivity: routes Responses/model traffic and MCP tool calls, applies transport and auth policies, and exports distributed telemetry. It carries requests; it is not the Actor sandbox and not the enforcement decision.
      
          
      Agent Substrate — execution and enforcement
      Creates disposable per-trial gVisor Actors with runtime identity and hosts the native Envoy egress hook on the Actor's store-claim path. That claim gate is the actual pre-execution boundary: enforcement happens outside the agent's cooperative loop.
      
          
      Banking bridge and state store
      The bridge validates each proposal and prepares it with the store, which binds the exact action and context to an immutable ticket and later commits state, receipts and evidence atomically outside disposable Actors.
      
          
      Reviewers (one per route)
      The classifier performs one encoder forward pass with frozen calibration in the host process; the LLM reviewer returns a generative verdict through the same shared gateway. Both receive the same contextual input at the same native boundary.
      
          
      MLflow evidence
      Persisted traces, spans and gateway exports, read back after reconciliation. Gateway span durations arrive from persisted readback and are labelled as observations, not live gateway internals.
